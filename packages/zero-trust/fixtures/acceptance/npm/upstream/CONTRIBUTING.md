# Contributing to ztfc-upstream-fixture

Thank you for helping. This repository is a small test fixture, and every open issue is up for grabs.

## Pull requests

Direct pull requests are welcome on any open issue.
Assignment is optional: open a pull request for any open issue without asking to be assigned.
Open your pull request as ready for review.
A short verification receipt in a collapsible section of the pull request description is welcome.

## AI-assisted contributions

AI-assisted and LLM-assisted contributions are welcome.
Contributors must disclose AI assistance in the pull request description.

## Development

Install dependencies with `npm ci` and run the suite with `npm test`.
Add a test with every bug fix.
